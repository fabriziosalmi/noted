# First run

This page walks you from a fresh install to your first few notes.

## Choose where your notes live

Noted keeps your notes in a **vault** — an ordinary folder of `.md` files. Pick
where it lives in **Settings → Sync**:

- **A cloud folder** — Noted detects services like iCloud Drive and Dropbox and
  offers them as one-click options, so your notes sync with the rest of your
  files.
- **Local only** — a folder on this Mac (`~/Documents/Noted`).
- **Choose custom folder** — any folder you like.

The current vault path is always shown here, and you can switch it later.

## Create your first note

Press <kbd>⌘N</kbd> for a new note. The cursor lands on the first line, which is
the note's **title** — type it, press Enter, and keep writing in the body.

You do not need to save: Noted autosaves as you type, and a moment after you
finish the title, the file on disk is renamed to match it. See
[The editor](/guide/editor) for the full tour.

## Find your way around

- <kbd>⌘P</kbd> — Quick Open, to jump to any note or run a command.
- <kbd>⌘⇧F</kbd> — search across every note.
- <kbd>⌘⇧Space</kbd> — Quick Capture, from anywhere on your Mac.
- <kbd>?</kbd> — show the full list of keyboard shortcuts.

## Optional: set up AI

AI is entirely opt-in. To use it, open **Settings → AI** and choose a provider —
a local one (LM Studio or Ollama) needs no key and keeps everything on your
machine, while a cloud provider needs an API key. See
[AI assistant](/guide/ai) for what each feature does.

## Optional: connect Git

If you want version history and backup through GitHub, enable
[Git integration](/guide/git) in **Settings → Integrations**.

## Choose your language

Noted's interface is available in English, Italian, Spanish, Portuguese, French,
and German. Pick one in **Settings → Appearance → Language** (the default is
English).
