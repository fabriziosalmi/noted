# Keyboard shortcuts

The modifier is <kbd>⌘</kbd> (Command) on macOS. Press <kbd>?</kbd> anywhere
outside a text field to open this list inside the app.

## General

| Shortcut | Action |
| --- | --- |
| <kbd>⌘P</kbd> | Quick Open |
| <kbd>⌘⇧F</kbd> | Search all notes |
| <kbd>⌘S</kbd> | Save |
| <kbd>⌘F</kbd> | Find in note |
| <kbd>⌘\\</kbd> | Focus mode |
| <kbd>⌘Z</kbd> | Undo |
| <kbd>⌘⇧Z</kbd> | Redo |
| <kbd>?</kbd> | Show keyboard shortcuts |

## AI

| Shortcut | Action |
| --- | --- |
| <kbd>/</kbd> | Slash (AI) commands |
| <kbd>⌘L</kbd> | Trigger ghost text (manual) |
| <kbd>Tab</kbd> | Accept ghost text |
| <kbd>Esc</kbd> | Dismiss ghost text |

## Formatting

| Shortcut | Action |
| --- | --- |
| <kbd>⌘B</kbd> | Bold |
| <kbd>⌘I</kbd> | Italic |
| <kbd>⌘E</kbd> | Inline code |
| <kbd>⌘⌥1</kbd> | Heading 1 |
| <kbd>⌘⌥2</kbd> | Heading 2 |
| <kbd>⌘⌥3</kbd> | Heading 3 |

## Notes

| Shortcut | Action |
| --- | --- |
| <kbd>⌘N</kbd> | New note |
| <kbd>⌘⇧Space</kbd> | Quick Capture (works even when Noted is not focused) |
| <kbd>⌘,</kbd> | Preferences |
| Double-click a note in the sidebar | Rename |
| <kbd>Mod+Enter</kbd> on a wikilink | Follow the link |
