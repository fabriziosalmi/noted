# Keyboard shortcuts

The modifier is <kbd>⌘</kbd> (Command) on macOS and <kbd>Ctrl</kbd> on Windows and Linux. Press <kbd>?</kbd>
anywhere outside a text field to open this list inside the app.

## General

| Shortcut | Action |
| --- | --- |
| <kbd>⌘K</kbd> | Quick Open (with text selected in a note: link it) |
| <kbd>⌘[</kbd> / <kbd>⌘]</kbd> | Back / Forward through the notes opened (also the mouse's side buttons) |
| <kbd>⌘P</kbd> | Print current note |
| <kbd>⌘⇧F</kbd> | Search all notes |
| <kbd>⌘S</kbd> | Save |
| <kbd>⌘F</kbd> | Find in note |
| <kbd>⌘⌥F</kbd> (macOS), <kbd>Ctrl+H</kbd> (Windows, Linux) | Find and replace |
| <kbd>⌘\\</kbd> | Focus mode |
| <kbd>⌘Z</kbd> | Undo |
| <kbd>⌘⇧Z</kbd> | Redo |
| <kbd>⌘+</kbd> / <kbd>⌘−</kbd> / <kbd>⌘0</kbd> | Zoom in / out / actual size |
| <kbd>?</kbd> | Show keyboard shortcuts |

## AI

| Shortcut | Action |
| --- | --- |
| <kbd>/</kbd> | Slash (AI) commands |
| <kbd>⌘L</kbd> | Trigger ghost text (manual) |
| <kbd>Tab</kbd> | Accept ghost text |
| <kbd>Esc</kbd> | Dismiss ghost text |

## Formatting

| Shortcut | Action |
| --- | --- |
| <kbd>⌘B</kbd> | Bold |
| <kbd>⌘I</kbd> | Italic |
| <kbd>⌘E</kbd> | Inline code |
| <kbd>⌘⌥1</kbd> | Heading 1 |
| <kbd>⌘⌥2</kbd> | Heading 2 |
| <kbd>⌘⌥3</kbd> | Heading 3 |
| <kbd>⌘K</kbd> with text selected | Link the selection |
| <kbd>⌘</kbd>-click a web link | Open it in the browser (a plain click edits it) |

## Notes

| Shortcut | Action |
| --- | --- |
| <kbd>⌘N</kbd> | New note |
| <kbd>⌘⇧Space</kbd> | Quick Capture (works even when Noted is not focused) |
| <kbd>⌘,</kbd> | Preferences |
| Double-click a note or folder in the sidebar, or <kbd>F2</kbd> | Rename |
| Right-click | Cut, copy, paste, spelling suggestions, link actions |
| <kbd>Mod+Enter</kbd> on a wikilink | Follow the link |
